# Windows 版 UI 设计规范 —「Lumen 流明」

> 轻盈简约 · 光感 · 毛玻璃。替换 Tauri 版的 "Ember Glass"（深色琥珀玻璃）。
> 适用范围：Windows 原生版（WPF）全部界面：宠物气泡、AI 对话、浮球、托盘菜单、设置页、弹幕、引导页。

---

## 1. 设计原则

1. **轻**：视觉重量减到最低——细描边、小号字、充足留白、低饱和配色。桌宠是常驻桌面的东西，必须"看得见但不打扰"。
2. **光感**：玻璃拟态（毛玻璃 + 高光）为唯一质感语言，不用重阴影、不用渐变背景墙。
3. **克制动效**：动效 ≤300ms、有目的（反馈/引导），只出现在交互点，不搞装饰性循环动画。
4. **一屏一重点**：任何界面只突出一个主操作，其余弱化。
5. **跟手与跟随**：深/浅色跟随系统；字号跟随系统缩放；高 DPI 无损。

## 2. 设计语言

### 2.1 色板（浅色为主，深色自动跟随）

**浅色（默认）**

| Token | 值 | 用途 |
|---|---|---|
| `bg/base` | `#F7F8FA` | 页面底色（冷白，比纯白柔和） |
| `surface/glass` | `rgba(255,255,255,0.62)` + 毛玻璃 | 卡片、面板 |
| `stroke` | `rgba(28,32,40,0.08)` | 1px 描边 |
| `text/primary` | `#1B1F26` | 正文 |
| `text/secondary` | `#6A7280` | 辅助说明 |
| `text/tertiary` | `#A0A8B4` | 占位、禁用 |
| `accent` | `#FF8A65` → `#FFB38A`（珊瑚橙渐变） | 主强调（暖，宠物感） |
| `accent/soft` | `rgba(255,138,101,0.12)` | 强调底 |
| `mint` | `#4ECBA5` | 成功/等级/正反馈 |
| `sky` | `#5B9DF0` | 信息/链接/AI 标识 |
| `danger` | `#E5544B` | 危险操作 |
| `pet-shadow` | `rgba(30,34,42,0.14)` | 悬浮阴影（只此一档，不用多重阴影） |

**深色（自动跟随系统）**

| Token | 值 |
|---|---|
| `bg/base` | `#17191D` |
| `surface/glass` | `rgba(36,40,46,0.6)` + 毛玻璃 |
| `stroke` | `rgba(255,255,255,0.08)` |
| `text/primary` | `#EDEFF2` |
| `accent` | `#FF9E73` |

### 2.2 字体

- UI：`Segoe UI Variable` / 中文回退 `Microsoft YaHei UI`
- 数字/等级：`Segoe UI Variable Display`，`FontFeature "tnum"`（等宽数字）
- 尺寸梯度：`11 / 12 / 13 / 15 / 20`px（13px 为正文基准，比现在 Tauri 版小一号，更轻）
- 行高：1.5；标题 1.3

### 2.3 形状与阴影

- 圆角：卡片 `14px`，控件 `10px`，胶囊按钮 `999px`，气泡 `18px`
- 阴影只有一档：`0 8px 24px rgba(30,34,42,0.10)`（浅色）/ 深色模式加深至 `0.22`
- 玻璃卡片：毛玻璃 + 1px 顶部高光 `inset 0 1px 0 rgba(255,255,255,0.5)`（深色 `0.08`）

### 2.4 动效规范

| 场景 | 时长 | 曲线 |
|---|---|---|
| 气泡弹出 | 180ms | `cubic-bezier(0.34, 1.56, 0.64, 1)`（轻微过冲弹簧） |
| 面板/菜单出现 | 150ms | `ease-out`，scale 0.97→1 + 淡入 |
| 文字/内容切换 | 150ms | `ease`，交叉淡入 |
| 弹幕滑入 | 无弹跳，匀速滚动 + 首尾 8% 渐变透明 |
| 心情/等级切换 | 200ms | 交叉淡入 + 微光晕一次 |

原则：**没有循环动画**（进度条除外）；hover 反馈 = 底色变化 + 1px 位移，不做缩放。

### 2.5 图标

- 微软开源 `Fluent System Icons`（Regular 线性风格），统一 1.5px 线宽
- 不用 emoji 做功能图标（只在空状态插画里允许）

## 3. 桌面元素与交互模式（先看这节）

**桌面上常驻的只有两样：宠物（含气泡）和浮球。** 其余全是可选功能，弹幕与对话是互斥的输出模式。

```
桌面常驻（永远在）        功能（全部可关，弹幕/对话二选一）
┌─────────────┐         ┌─────────────────────────────┐
│ 宠物窗口 ×N   │         │ AI 总开关（一键全关 → 纯桌宠）   │
│  · 多只并存，  │         │  ├ 截屏分析开关                │
│    每只一窗口  │         │  ├ 输出模式：弹幕/对话/静默     │
│  · 每只独立    │         │  ├ 主动互动开关 + 频率档        │
│    显隐/大小/  │         │  ├ 记忆开关（隐私）            │
│    漫游配置   │         │  ├ 屏幕上下文开关（对话带截图）  │
│  · 互动气泡   │         │  ├ 每日总结开关                │
└─────────────┘         │  ├ 总结图开关（默认关）         │
┌─────────────┐         │  └ 语音朗读开关（默认关）        │
│ 浮球         │         │  （全屏层/对话窗，模式激活时才创建）│
│  · 左键气泡菜单│         └─────────────────────────────┘
│    （发文字，  │
│     全员/单只） │
│  · 右键设置   │
└─────────────┘
```

**开关层级**：AI 总开关（关 = 全部失效，无截屏/网络/后台进程）→ 各功能独立开关（设置页 AI 助手页唯一总控；浮球菜单只放输出模式快捷切换）

- **多宠物**：可同时展示多只（每实例一个窗口，继承现状 `PetStore.instances`），每只独立位置/大小/漫游/显隐；添加与删除在设置页
- **快速气泡（继承现状）**：浮球左键菜单输入文字 → 广播给**所有宠物同时说**；**点击宠物本体** → 单只说或全员说（`LEFT_CLICK_KEY`：none/self/all 可配）；预设池 + 显示时长（默认 4s）在设置页配置
- **显隐分两级**：全局显隐（托盘/浮球开关，一键隐藏全部，继承现状 `set_desktop_pets_visible`）+ 单只显隐（设置页宠物卡片）
- **开关位置**：浮球左键菜单（快速切换输出模式）+ 设置页（AI 助手页：分析总开关、输出模式、云端/本地）
- **切换即销毁**：从弹幕切到对话时弹幕层窗口销毁；关闭 AI 时对话气泡窗口销毁。**不激活的模式不创建窗口、不占渲染循环、零资源**
- **气泡分两类**：宠物自身互动气泡（常驻，喂食/心情/等级）与 AI 对话气泡（对话模式专属，见 3.2）——视觉同语言但位置/行为不同，互不混淆

## 3.1 宠物气泡（桌面常驻）

- 毛玻璃胶囊（`surface/glass` + 毛玻璃 + 1px 描边），圆角 18px，**最大宽度 240px**，最小高度 32px
- 尾巴：底部居中 8px 小三角，指向宠物头顶（跟随宠物位置）
- 文字：13px 主色，单行省略，气泡宽度自适应内容
- 出现：180ms 弹簧弹出；消失：120ms 淡出向下 4px
- **快速气泡**（继承现状 `QuickBubbleController`）：浮球发送的文字以快速气泡显示，默认 4s 消失（设置页可调 1-10s）；所有宠物同时显示同一文字时保持视觉同步（同时弹出、同时消失）
- 头像角标（可选）：气泡左缘 20px 圆形宠物头像，用于对话场景区分身份
- **特殊状态**：心情（开心/饿/困）在气泡左侧加 16px 状态点，色随心情（mint/amber/sky）

### 3.2 AI 对话气泡（对话模式专属，可开关）

> 仅在输出模式 = 对话时存在；切到弹幕/静默或关闭 AI 时窗口销毁。

- 聊天气泡式：宠物在左（白玻璃），用户在右（accent 12% 底）
- 输入框：胶囊形，毛玻璃，占位文字"和你的桌宠说点什么…"，Enter 发送 / Shift+Enter 换行
- 打字机效果：文字逐字显示（40ms/字），光标为细竖线呼吸
- 顶部状态条：模型名 + **人格名（可点击切换）** + 状态点（思考中 = sky 呼吸点；回复 = mint；错误 = danger）
- **屏幕上下文**：是否携带当前屏幕描述由 AI 助手页「屏幕上下文开关」控制（默认关）；关闭时对话仅基于聊天内容
- 历史滚动：最新在底部，自动吸底；超过 20 条折叠为"查看更早对话"

### 3.3 浮球（桌面入口）

- 48px 圆球：毛玻璃球体 + 顶部高光（模拟光感）+ 底部柔和投影
- hover：球体放大到 52px（150ms），显示 8px 光环
- 左键：弹出快捷菜单（毛玻璃卡片，圆角 14px，动效 150ms），自上而下：
  1. **快速气泡区**（继承现状）：输入框 + 预设胶囊（点击填入，Shift+点击删除）+ 发送按钮 —— 发送即全员广播
  2. 分隔线
  3. **AI 输出模式行**：弹幕 / 对话 / 静默三选一（小图标 + 状态点）
- 右键：直接打开设置（与左键菜单区分：左键 = 常用操作，右键 = 管理）
- 球体内嵌当前选中宠物的活体动画（继承现状 `ballPet`，镜像设置页选中实例）
- 位置持久化；贴边自动吸附（靠边 60ms 滑入，仅露出 8px）

### 3.4 托盘菜单

- 自绘毛玻璃面板（不用系统 ContextMenu，保持设计一致性），圆角 14px
- 项：当前宠物头像（24px 圆形）+ 名称、**全局显示/隐藏宠物开关（一键隐藏全部，继承现状 `set_desktop_pets_visible`）**、休息提醒开关、设置、退出
- 分隔线用 1px `stroke`，悬停项底色 `accent/soft`
- 失去焦点自动关闭（150ms 淡出）

### 3.5 设置页（重头戏）

布局：**左侧 56px 图标导航 + 右侧内容区**，而非顶部标签栏——桌面工具页更符合"看一眼就懂"的习惯。

- 左导航：宠物、外观、AI 助手、提醒、语言、关于；选中项 = accent 圆角块 + 图标，未选中 = 透明 hover 微灰
- **AI 助手页**（新功能总入口，**所有 AI 开关的唯一总控页**）：
  - **AI 总开关**（顶部，关 = 全部 AI 功能关闭，纯桌宠）
  - 分析开关（截屏分析）· 输出模式三选一（弹幕/对话/静默，单选卡片）· 主动互动开关 + 频率档（少/中/多）· 记忆开关（隐私，关 = 不记录画像）· 屏幕上下文开关（隐私，默认关，开 = 对话请求携带当前屏幕描述）· 每日总结开关（默认开）· 总结图开关（默认关）· 语音朗读开关（默认关）· 简短回复开关（默认开，关 = 允许长回复）
  - **人格设置**（内置 7 种 + 自定义，见 `docs/ai-personas.md`）· 模型连接（`providers.json`：测试连接/能力徽章）· 生图连接 · 隐私说明入口
  - 浮球菜单只放输出模式快捷切换，不重复放开关
- **气泡设置**（继承现状 `ap_quick_bubbles` / `ap_quick_bubble_duration`）：预设气泡池多行编辑（每行一条）、显示时长滑杆（1-10s）、**点击宠物行为三选**（无动作 / 单只随机说 / 全员随机说，对应 `LEFT_CLICK_KEY`）
- 内容区：单列卡片流（最大宽 720px 居中），卡片 = 毛玻璃 + 14px 圆角，卡片间距 12px
- **宠物卡片**：128px 实时动画预览（直接用渲染器跑，不是静态图）+ 名称 + 等级徽章（mint 胶囊）+ **单只显隐开关**；hover 卡片浮起 2px
- **多宠物管理**：卡片右上角「添加宠物 / 移除」；移除前确认（气泡内联确认，不弹系统框）；卡片间可拖拽排序（多只并存时的桌面排布参考）
- **导入自定义宠物**：整卡拖拽文件进入（虚线边框 + accent 提示文案），或点击选择文件；导入后立即切片预览（见 3.6）
- **开关**：自绘（40×22 轨道 + 20px 圆形滑块，accent 开启色，150ms 弹性）
- **滑杆**：细 3px 轨道 + 20px 圆形滑块，数值实时显示右侧
- **空状态**：居中 64px 线性插画（Fluent 风格）+ 一句文案 + 主按钮
- 深浅模式：设置页内提供"跟随系统 / 浅色 / 深色"三选
- 设置页是唯一允许滚动的地方；滚动条细 6px、悬停加深

### 3.6 切片预览（自定义宠物）

- 导入后直接显示：精灵原图缩略 + 自动切出的**帧网格线**（1px accent 虚线）覆盖图
- 下方横向滚动帧条：每帧 56px 缩略图，hover 播放该行动画
- 每行动画可命名/绑定状态（闲逛、睡觉、开心……），绑定用下拉胶囊
- 出错提示（无可检测的透明带）：卡片内联警示条（danger 12% 底），提供"手动网格"输入（列×行）

### 3.7 养成视觉（成长表现——精灵图不变，靠叠加与行为）

> 宠物精灵图是固定的 72 帧，**不依赖新外观素材**。成长感由三层构成：行为解锁 + 视觉叠加 + 身份表现。

**Token 经济学（继承现状 `care.ts`，对齐 `PetCare.swift`）**
- 5000 token = 1 XP；完成一次会话 = 25 XP（比纯烧 token 划算）
- AI 接入后 token 来源：对话模式（每次对话的输入+输出 token）、弹幕/分析模式（每次截屏分析调用）；静默模式无消耗无成长
- 防刷护栏：重复内容对话不重复计 XP；XP 只升不降；不吃 token 不会死（饥饿只影响心情气泡文案，不惩罚）

**五阶段 × 三层表现**

| 阶段 | 等级 | 行为解锁（用现有 72 帧 + 漫游模式） | 视觉叠加（WPF 渲染层） |
|---|---|---|---|
| Hatchling 幼体 | 0-4 | 仅 stay + wander，走得慢、睡得久（幼崽感） | 无，朴素 |
| Companion 伙伴 | 5-9 | 解锁 cursor（追鼠标） | 脚下 8px 柔和光晕（mint） |
| Scout 侦察兵 | 10-19 | 解锁 climb（爬屏幕边缘），漫游速度升一档 | 轮廓辉光（sky）；升级瞬间星点迸发一次 |
| Hero 英雄 | 20-34 | 全部漫游模式，点击响应更快、互动气泡更频繁 | 金色辉光；idle 时偶飘 1-2 星点粒子 |
| Legend 传说 | 35+ | 同上全开 | 金辉光 + 头顶小皇冠（矢量小贴图）+ 星点粒子 |

**其他成长表现**
- 气泡样式升级：Hatchling 朴素白气泡 → Legend 金边毛玻璃气泡
- 升级反馈：辉光闪一次 + 星点迸发 + 气泡显示「进化！Scout」（只升级的那只表现，不干扰其他宠物）
- 身份层（已有）：阶段名、Lv 徽章、14 个成就徽章、连续天数
- 原则：视觉克制（柔和光晕不是刺眼特效），符合 Lumen 轻盈基调

### 3.8 弹幕（弹幕模式专属，可开关）

> 仅在输出模式 = 弹幕时创建全屏层；切到对话/静默或关闭 AI 时窗口销毁，不残留进程与渲染循环。

- 文字：13px，白色 90% + 4px 柔黑阴影（任何壁纸上可读），首尾 8% 水平渐变淡出
- 滚动：右→左匀速（12s 横穿 1920px），无弹跳
- 优先级：AI 事件弹幕（accent 色左边 4px 竖条）> 普通弹幕；同屏上限 12 条，超出排队
- **多宠物身份标识**：弹幕文案带宠物名前缀（小头像 + 名字，如「🐶 小奶狗：姐姐好棒呜呜~」）——同事件各宠物按自己人格发弹幕，像直播间不同用户；用户主动发的快速气泡不带前缀（是用户自己说的）
- 出现方式：淡入 200ms，不是硬生生滑入
- 关闭：设置里开关（默认开）；不拦截鼠标（完全穿透）

### 3.9 引导页 / 隐私说明（AI 功能）

- 三步卡片横排：① 它能看到你的屏幕（图示：屏幕缩略 + 取景框）② 它只在本地判断"你在做什么" ③ 云端对话需你开启
- 主按钮：accent 胶囊"开始使用"；副按钮：文字链接"查看隐私说明"
- 整体保持轻盈：白底 + 三个玻璃卡片，不搞全屏插画

## 4. 与旧版（Ember Glass）的差异摘要

| 维度 | Ember Glass（旧） | Lumen（新） |
|---|---|---|
| 基调 | 深色暖调玻璃 | 浅色冷白玻璃（深色跟随系统） |
| 强调色 | 琥珀金 | 珊瑚橙渐变 |
| 阴影 | 双层重阴影 | 单档轻阴影 |
| 字体 | 13px 基准 | 13px 基准（数字等宽） |
| 设置布局 | 顶部标签栏 | 左侧图标导航 |
| 宠物展示 | 静态缩略 | 实时动画预览卡片 |
| 动效 | 无统一规范 | 统一 150-300ms 规范 |

## 5. WPF 技术实现要点

| 需求 | 实现 |
|---|---|
| 毛玻璃 | Win11：`DWMWA_SYSTEMBACKDROP_TYPE` = Acrylic/Mica；Win10 1803+：`SetWindowCompositionAttribute` 模糊。**注意**：毛玻璃窗口不能用 `AllowsTransparency=true`，用 `WindowChrome` + 半透明背景 + DWM 模糊 |
| 圆角窗口 | Win11 `DWMWA_WINDOW_CORNER_PREFERENCE`；老系统自绘圆角 + 透明区域 |
| 宠物窗口（像素风） | 当前 WPF 兼容 presenter 保持 `AllowsTransparency=true`；普通精灵帧复用冻结 `BitmapSource`，动态成长叠加才走 `WriteableBitmap`。高频透明 presenter 迁移到原生 Composition HWND 时，精灵、气泡和效果必须同树渲染 |
| 动效 | 自写轻量动画助手（`AnimationHelper`，TimeSpan + easing 曲线），不引重库；气泡弹簧用 `BackEase` 或贝塞尔关键帧 |
| 图标 | Fluent System Icons 的 `Path` 数据转 `Geometry` 资源字典 |
| 深色跟随 | WPF 监听系统主题（`SystemEvents.UserPreferenceChanged`）切换资源字典 |
| 字体缩放 | WPF 默认 DPI 感知（PerMonitorV2），只需在 `app.manifest` 声明 |
