# DesktopPet Windows 手动拖动审查

## 不变量

- 宠物手势只能由同一活动 `pointerId` 完成：pointerdown 后必须捕获指针，且 `pointerup`、`pointercancel`、`lostpointercapture` 中只有第一个事件可以结束手势。小球现有绑定已实现这一模式：[floating-ball-pointer.ts](C:/sudy/github/DesktopPet/windows/src/floating-ball-pointer.ts:27) 至 [floating-ball-pointer.ts](C:/sudy/github/DesktopPet/windows/src/floating-ball-pointer.ts:42)、[floating-ball-pointer.ts](C:/sudy/github/DesktopPet/windows/src/floating-ball-pointer.ts:44) 至 [floating-ball-pointer.ts](C:/sudy/github/DesktopPet/windows/src/floating-ball-pointer.ts:69)。

- canvas 只有命中 sprite 才能开始候选手势；透明 canvas 区域必须继续穿透。当前门槛在 [pet-window.ts](C:/sudy/github/DesktopPet/windows/src/pet-window.ts:316) 至 [pet-window.ts](C:/sudy/github/DesktopPet/windows/src/pet-window.ts:324)。

- 未超过 4px 的 canvas 手势必须保持为 click 并仅执行 `onPetClick`；超过阈值才取消 throw、开始拖动。当前 canvas 行为见 [pet-window.ts](C:/sudy/github/DesktopPet/windows/src/pet-window.ts:294) 至 [pet-window.ts](C:/sudy/github/DesktopPet/windows/src/pet-window.ts:337)，小球的阈值实现在 [floating-ball-drag.ts](C:/sudy/github/DesktopPet/windows/src/floating-ball-drag.ts:60) 至 [floating-ball-drag.ts](C:/sudy/github/DesktopPet/windows/src/floating-ball-drag.ts:103)。

- 每次手动窗口移动必须以 Tauri 的物理 `cursorPosition()` 减去 pointerdown 时固定的物理 grab offset 计算，并用 `PhysicalPosition` 写入。小球已遵守该契约：[floating-ball.ts](C:/sudy/github/DesktopPet/windows/src/floating-ball.ts:31) 至 [floating-ball.ts](C:/sudy/github/DesktopPet/windows/src/floating-ball.ts:36)、[floating-ball-drag.ts](C:/sudy/github/DesktopPet/windows/src/floating-ball-drag.ts:120) 至 [floating-ball-drag.ts](C:/sudy/github/DesktopPet/windows/src/floating-ball-drag.ts:128)。`cursorPosition` 的 Tauri 声明返回 `PhysicalPosition`（`windows/node_modules/@tauri-apps/api/window.d.ts:1820`）。

- pointerup/cancel 后，必须先等待最后一次合并移动完成，再记录最终样本、解除 engine dragging 并持久化。小球控制器已保证末次移动先于 `persistPosition`：[floating-ball-drag.ts](C:/sudy/github/DesktopPet/windows/src/floating-ball-drag.ts:105) 至 [floating-ball-drag.ts](C:/sudy/github/DesktopPet/windows/src/floating-ball-drag.ts:136)。

- 漫游/physics 只能经 `currentLogicalPos` 和 `setLogical` 使用逻辑坐标；物理到逻辑的缓存、缩放变更和乱序保护必须保持单一来源：[roam/window.ts](C:/sudy/github/DesktopPet/windows/src/roam/window.ts:24) 至 [roam/window.ts](C:/sudy/github/DesktopPet/windows/src/roam/window.ts:123)。

- 拖动期间，pet window 必须保持可接收鼠标。Rust 点击穿透循环在命中区域外设置 `set_ignore_cursor_events(true)`：[lib.rs](C:/sudy/github/DesktopPet/windows/src-tauri/src/lib.rs:669) 至 [lib.rs](C:/sudy/github/DesktopPet/windows/src-tauri/src/lib.rs:688)。手动拖动期间需要按 label 的活动拖动租约，强制 `false`；所有收尾和失败路径必须释放该租约。

- 成功的手动移动必须进入抛掷采样。当前 engine 只在 30ms tick 读取位置：[roam/engine.ts](C:/sudy/github/DesktopPet/windows/src/roam/engine.ts:87) 至 [roam/engine.ts](C:/sudy/github/DesktopPet/windows/src/roam/engine.ts:103)；physics 至少需要两个、相隔 20ms 的样本：[roam/physics.ts](C:/sudy/github/DesktopPet/windows/src/roam/physics.ts:24) 至 [roam/physics.ts](C:/sudy/github/DesktopPet/windows/src/roam/physics.ts:40)。

- 落点和 throw/fall 终点都必须持久化到既有 `PetPositionMap`/`pet-positions.json`。当前 Rust 只约每 1.02 秒写一次：[lib.rs](C:/sudy/github/DesktopPet/windows/src-tauri/src/lib.rs:700) 至 [lib.rs](C:/sudy/github/DesktopPet/windows/src-tauri/src/lib.rs:730)。

## 风险

- High: 直接复用小球控制器会遗漏宠物的透明点击穿透循环。小球没有 `set_ignore_cursor_events` 路径；宠物的串行异步 `setPosition` 落后于光标时，Rust 可按旧窗口位置把窗口切换为忽略鼠标，导致 move/up 丢失。证据：[floating-ball-drag.ts](C:/sudy/github/DesktopPet/windows/src/floating-ball-drag.ts:105) 至 [floating-ball-drag.ts](C:/sudy/github/DesktopPet/windows/src/floating-ball-drag.ts:128)，[lib.rs](C:/sudy/github/DesktopPet/windows/src-tauri/src/lib.rs:669) 至 [lib.rs](C:/sudy/github/DesktopPet/windows/src-tauri/src/lib.rs:688)。

- High: 只调用现有 `setDragging(true/false)` 不会可靠保留快速甩动。一个小于 30ms 的拖放可以在 tick 采到两个位置前结束，`releaseVelocity()` 返回 null，不会启动 throw/fall。证据：[roam/engine.ts](C:/sudy/github/DesktopPet/windows/src/roam/engine.ts:87) 至 [roam/engine.ts](C:/sudy/github/DesktopPet/windows/src/roam/engine.ts:103)，[roam/physics.ts](C:/sudy/github/DesktopPet/windows/src/roam/physics.ts:30) 至 [roam/physics.ts](C:/sudy/github/DesktopPet/windows/src/roam/physics.ts:40)。

- High: 仅依赖秒级后台保存无法保证最终位置。拖放或 throw 后立即退出时，最近位置可未写入。证据：[lib.rs](C:/sudy/github/DesktopPet/windows/src-tauri/src/lib.rs:700) 至 [lib.rs](C:/sudy/github/DesktopPet/windows/src-tauri/src/lib.rs:730)。需要类似 `persist_floating_ball_position` 的、验证 pet label 并写入同一 position map 的命令；小球先完成移动再持久化的先例在 [floating-ball-drag.ts](C:/sudy/github/DesktopPet/windows/src/floating-ball-drag.ts:131) 至 [floating-ball-drag.ts](C:/sudy/github/DesktopPet/windows/src/floating-ball-drag.ts:135)。

- Medium: canvas 与 bubble 的现有语义不一致。canvas 的静态释放执行 click；bubble 在 mousedown 立即开始原生拖动且不会执行 `onPetClick`。证据：[pet-window.ts](C:/sudy/github/DesktopPet/windows/src/pet-window.ts:316) 至 [pet-window.ts](C:/sudy/github/DesktopPet/windows/src/pet-window.ts:347)。替换时必须明确定义 bubble 静态释放是否仍为无操作；不能无意采用小球的 280ms click 时限，因为宠物 canvas 目前没有时限。

- Medium: 把 `PointerEvent.screenX/screenY`、`LogicalPosition` 或动态变化的 DPR 直接用于拖动写入会破坏混合 DPI。宠物命中矩形已经明确由 CSS px 转物理 px：[pet-window.ts](C:/sudy/github/DesktopPet/windows/src/pet-window.ts:364) 至 [pet-window.ts](C:/sudy/github/DesktopPet/windows/src/pet-window.ts:393)。抓取 offset 必须在 pointerdown 固定为 `clientX/clientY * 初始 devicePixelRatio`，跨显示器移动时不可重算。

## 必测项

- canvas sprite 内 pointerdown 捕获；透明 canvas 区域不捕获、不关闭 popover、不移动窗口。
- bubble 与 canvas 各自的静态 release 语义：canvas 恰好一次 `onPetClick`；bubble 按已确定的显式契约验证，且不隐式继承小球菜单行为。
- 阈值边界：移动恰好 4px 不拖动，超过 4px 才调用 drag start；右键不开始手势。
- `pointerup`、`pointercancel`、`lostpointercapture`：只结束一次，均释放 capture、Rust drag lease、engine dragging；任一 `setPosition`/persist rejection 后不能遗留 dragging/lease。
- 末次时序：延迟最后一次 `setPosition`，断言 `setDragging(false)`、最终逻辑样本和持久化在该 Promise 完成之后发生。
- 快速 throw：两个成功手动移动样本在小于 engine tick 间隔内产生，release 后断言启动 `applyThrow`；climb mode 断言启动 `applyFall`；低速释放不启动物理。
- 混合 DPI：初始 DPR 1.5/2 的 `client` offset 转为物理 px；跨缩放显示器仍使用初始固定物理 offset；晚到 `onMoved` 与 `onScaleChanged` 不覆盖最新逻辑位置。应扩展 [roam/window.test.ts](C:/sudy/github/DesktopPet/windows/src/roam/window.test.ts:151) 至 [roam/window.test.ts](C:/sudy/github/DesktopPet/windows/src/roam/window.test.ts:175) 的缓存竞态覆盖。
- 点击穿透租约：活动拖动期间，即使光标暂时不在旧 hit rect，Rust 仍请求 `set_ignore_cursor_events(false)`；release 后恢复正常 hit-rect 判断。应提取无 Tauri 依赖 helper，按 [lib.rs](C:/sudy/github/DesktopPet/windows/src-tauri/src/lib.rs:55) 至 [lib.rs](C:/sudy/github/DesktopPet/windows/src-tauri/src/lib.rs:66) 的风格单测。
- 持久化：合法 pet label 在末次移动后立即写入现有 `PetPositionMap`；非法/non-pet label 无副作用；throw/fall 结束后再次写入终点。
