This removes the dependency on `startDragging()` that caused the original Windows mouseup-loss failure. `finishBallDrag` clears `activeBallDrag` before releasing capture (`:238-246`), so the resulting `lostpointercapture` event is idempotent.
- Correct: `windows/src/floating-ball.ts:200-256` coalesces outstanding `setPosition` calls and updates `latestX/latestY` before the final queue. `persistBallPosition` awaits the move task before invoking persistence, which preserves the final queued drop coordinate in normal asynchronous ordering.

- **Important:** `windows/src/floating-ball.ts:195-210` mixes a start-monitor logical coordinate (`outerPosition / scaleFactor`) with `PointerEvent.screenX/screenY` deltas, then submits the result as `LogicalPosition`. This is not stable when a drag crosses monitors with different DPI scale factors: the initial scale factor is retained in `origin`, while Tauri can apply the target/current monitor scale factor for a later `setPosition`. Result: the orb can jump or land offset, and persisted coordinates can differ from the apparent drop location. Fix: use one normalized coordinate space for the full drag, preferably physical desktop coordinates through `PhysicalPosition`, with pointer coordinates converted consistently and monitor-scale transitions handled explicitly; add mixed-DPI cross-monitor coverage.
- **Important:** `windows/src/floating-ball.test.ts:8-29` is source-text assertion only. It verifies string presence/absence, not the behavioral regression: no pointer event sequence exercises capture, `pointerup`, `pointercancel`, `lostpointercapture`, final move queueing, or the ordering “last `setPosition` completes before persistence.” It would pass if `finishBallDrag` were disconnected from the listeners or if persistence occurred at the wrong time. Fix: extract the drag state machine behind injectable window/invoke dependencies, then add unit tests for click, threshold drag, captured pointerup, cancel/lost-capture cleanup, delayed `setPosition`, and persistence of the final coordinates.
