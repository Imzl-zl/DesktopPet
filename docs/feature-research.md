# 成熟产品功能调研与采纳决策

> 调研对象：桌宠类（BongoCat、元气桌面、bongo-cat-next）+ AI 陪伴类（Character.AI、星野、筑梦岛、心光/独响/悦流、Talkie、Replika）。
> 结论先行：**采纳 8 项**（P0 × 5，P1 × 3），**暂缓 3 项**，**明确不做 3 项**。

---

## 1. 调研发现（按产品）

### 桌宠类

| 产品 | 值得借鉴的功能 |
|---|---|
| **BongoCat**（Rust/Tauri，跨平台） | ① **键鼠同步动作**：根据键盘/鼠标/手柄操作同步宠物动作（核心卖点）② 自定义模型 ③ 隐私友好（离线） |
| **bongo-cat-next**（Tauri 2） | ① **全局快捷键**：`Ctrl+Alt+H` 显隐 / `Ctrl+Alt+S` 设置 / `Ctrl+Alt+Q` 退出 ② **动作选择器**：交互式播放动画 ③ 表情系统 ④ 透明度/镜像/点击穿透等个性化 ⑤ 性能指标公开：内存 <50MB、CPU <1%、启动 <2s、键鼠响应 <10ms |
| **元气桌面**（桌面美化套件） | 桌面整理/壁纸/便签等（与桌宠定位不同，仅参考"虚拟助手"入口）；互动壁纸的粒子特效思路可借鉴到养成视觉 |

### AI 陪伴类

| 产品 | 值得借鉴的功能 |
|---|---|
| **Character.AI**（2000 万 MAU，日均 2 小时） | ① **记忆系统**：几天前的对话细节还能主动提起（用户最称赞的功能）② **主动问候**：角色主动发消息 ③ **消息编辑/重写**、"从这里重新开始" ④ **群聊 Rooms**：多角色同框对话 ⑤ 示例对话 > 性格描述（创建角色时 10-20 段示例让风格更稳定） |
| **星野**（MiniMax） | ① **记忆簿**：长期记忆显式管理 ② 亲密度/关系成长 ③ 语音通话 ④ 形象/声音/人设/技能四维自定义 |
| **筑梦岛** | ① **亲密度玩法** ② 角色朋友圈/动态（"像真人社交"的沉浸感）③ 保存精彩对话为"梦境"可回顾 |
| **心光 / 独响 / 悦流**（日记陪伴） | ① **AI 写信**：隔段时间 AI 发来一封信，回顾记忆（碎片记忆的回忆视角）② 日记批注 |
| **Talkie / Replika** | 情感 TTS 语音（Talkie 强）；Replika 深关系养成 |

## 2. 采纳清单（结合本产品场景：像素桌宠 + AI 分析 + 弹幕/对话 + 多宠物 + 养成）

### P0 — 做，纳入 Phase 5/6（高价值，工作量可控）

**① 记忆系统（用户画像）** — 借鉴 C.AI / 星野记忆簿
- 结构化用户画像 JSON：称呼偏好、名字、作息规律（从截屏分析推断活跃时段）、常聊话题标签、最近对话摘要
- 注入方式：每轮请求携带画像摘要（不依赖向量库，桌宠场景用结构化记忆足够）
- 表现：隔天主动提起（"你昨晚又加班到两点"——配合主动互动）、对话中自然引用
- **记忆开关**（默认开；关 = 不记录画像、不注入，画像文件不落盘）
- 工作量：中（`MemoryStore.cs`：画像提取 + 摘要压缩 + 注入）

**② 主动互动（AI 驱动问候/评论）** — 借鉴 C.AI 主动问候 / 筑梦岛动态
- 现有 idle 台词升级为 AI 驱动：定时（早/晚/久坐提醒）+ 事件驱动（检测到用户切换窗口类型/长时间摸鱼/持续编码时，按当前人格评论）
- 输出走当前模式：弹幕 or 对话气泡
- **主动互动开关**（默认开）+ **频率档**（少/中/多）；**屏幕感知开关**（默认开，关 = 不再从截屏推断用户活动，定时问候仍可用）
- **多宠物分派（关键设计）**：
  - **同一事件，各自表达**：所有参与的宠物围绕同一事件，但每只按自己的人格独立生成内容（暖男"辛苦了" vs 小奶狗"姐姐好辛苦呜呜~"）
  - **谁来说**：默认每只宠物按事件相关性 + 轮换（round-robin）竞争，随机 1-2 只说；用户可设置"全员回应"（每只都生成）
  - **生成方式 = 并行独立请求**（不是合并一个请求——人格是 system prompt 差异，一个请求只有一个 system，合并会人格混淆）：
    - 全员回应时 N 只同时发请求（`Task.WhenAll`），并发上限由调度器控制（默认 3，见架构文档 `ModelRequestScheduler`）
    - 并行 = 一次等待时间（1-3s），串行 = N 倍延迟（5 只就 5-15s）
  - **快速气泡（用户主动发）不受影响**：保持现状广播同一句（用户指定的内容）
- 工作量：中低（PetAgent 事件分类 + 触发策略 + 分派器 + 请求调度器）

**③ 亲密度系统（关系成长）** — 借鉴筑梦岛/星野亲密度，与本产品养成体系衔接
- 新维度 `intimacy`（0-100）：随对话轮次、token 消耗、连续天数增长；长期不互动缓慢下降（不归零）
- 效果：人格表现随亲密度升级——称呼变化（"你"→"宝贝"）、关心频率、语言亲昵度（如暖男 Lv0 亲密度："注意休息"→ 高："昨天没睡好？我心疼"）
- 与现有 XP/等级的区别：XP = 养成数值（阶段/外观），亲密度 = **关系数值**（AI 表现），两者互相驱动
- **亲密度开关**（默认开；关 = 固定人格基础档，不随互动变化）
- 工作量：中（CareEngine 扩展 + 人格模板按亲密度分档）

**④ 全局快捷键** — 借鉴 bongo-cat-next
- `Ctrl+Alt+H` 显隐宠物 / `Ctrl+Alt+M` 切换输出模式 / `Ctrl+Alt+S` 设置 / `Ctrl+Alt+Q` 退出
- 工作量：低（`RegisterHotKey` P/Invoke）

**⑤ 对话增强** — 借鉴 C.AI
- 保留：**从这里重新开始**（聊崩了清空上下文重新聊，保留记忆/亲密度）、自定义人格表单加**示例对话**输入（2-5 段，借鉴"C.AI 示例 > 描述"经验）
- ~~重写回复~~：砍掉。对话场景不是写代码，重生成上一条回复没有使用场景
- 工作量：低

### P1 — 确认采纳，排期在 P0 之后

**⑥ 每日总结 + 总结图（宠物日记）** — 借鉴心光 AI 写信 + 现有生图能力（Tauri 版 `generate_image` / macOS 版 ImageGen 已有）
- 每天结束时 PetAgent 自动生成当日总结（做了什么/聊了什么/心情）
- **总结图**：总结文本 → 提示词工程（总结摘要 + 宠物形象描述 + Lumen 轻盈画风）→ 生图模型生成一张「当日总结图」——宠物日记的视觉封面
- 入口：设置页宠物卡片 → 查看日记（文本 + 图）；对话中可要求"今天干了啥""把昨天的总结画出来"；生成后宠物气泡提示"今天的总结图出炉啦~"
- 图可另存为壁纸/分享；生图开关独立可关（默认开，每日 1 张成本可控）
- **开关**：每日总结开关（默认开）+ 总结图开关（默认**关**——云端费用 + 隐私，显式开启）；**总结全局一份**（记录的是"你的一天"，多宠物共享，各宠物可就总结发评论）
- 工作量：中（复用总结流程 + `IImageProvider`，见架构文档 §3.4）

**⑦ 语音输出（TTS）** — 借鉴 Talkie/星野
- 对话模式可开启朗读（Windows 默认 SAPI 离线合成，音色可升级 OneCore 自然语音 / 用户自配 OpenAI 兼容端点；Edge TTS 免费接口经调研不可依赖——TLS 指纹 + 大陆 IP 地域风控，见 `windows-tts-design.md` §1.2），弹幕模式不朗读
- 开关默认关（避免打扰）；**语音开关**（AI 助手页，默认关）
- 工作量：中低

**⑧ 键鼠响应（Bongo Cat 式）** — 借鉴 BongoCat
- 全局键盘/鼠标钩子：用户打字时宠物播放"敲键盘"动作、鼠标快速移动时宠物看鼠标
- 风险：现有 72 帧精灵可能没有敲键盘动画行 → 实现为**行为增强**（打字时加速当前动画行 + 高频互动表现），精灵有对应行则直接绑定；无则跳过该动作
- **键鼠响应开关**（默认开；关 = 不监听全局键鼠钩子）
- 工作量：中（`InputHook` 全局钩子 + 动画行映射）

### 暂缓（P2，后续评估）

- **多宠物群聊**（C.AI Rooms）：多只 AI 宠物同框对话/对同一屏幕事件轮流评论。天然契合多宠物，但模型调用链路复杂（多角色上下文管理），先做"多宠物轮流评论同一事件"的简单版再评估
- **角色背景故事字段**：内置人格加详细版背景故事（可选开启，当前精简版够用）
- **点击穿透/透明度/镜像**等个性化微调：bongo-cat-next 有，桌宠本体优先级低，设置页有空位再加

### 明确不做

- **角色社区/UGC 分享**（C.AI/筑梦岛）：产品形态不符，太重
- **游戏化抽卡/内购**（Talkie）：不符合轻量定位
- **触觉反馈**：手机功能，桌面无意义

## 3. 与现有功能的关系图

```
现有:  XP/等级/阶段（养成数值） + 人格（语气） + AI 分析（屏幕感知）
新增:  亲密度（关系数值）  +  记忆（用户画像）  +  主动互动（AI 驱动输出）
                          ↓
        人格表现 = f(人格模板, 亲密度档位, 记忆画像)
        养成表现 = f(XP 阶段)   ← 不变（§3.7 设计）
```

- 亲密度和 XP 是两条线：XP 决定"宠物长啥样/多活泼"，亲密度决定"AI 多懂你/多亲近"
- 记忆 + 主动互动让宠物从"被动应答"变成"主动陪伴"——这是 AI 陪伴类产品验证过的核心体验
